# Remix of FainShow: Filme și Shorts

Create a simple light app called FainShow, fast, no freeze.

Home with 6 movies, Shorts with 3 videos play on click only, Shop with 4 products.

Bottom menu: Home, Shorts, Shop. Dark theme, red black, Romanian.

This project was built with [Lovable](https://lovable.dev).
